# Hyrax Engine (Fork of O3DE 26.05)

Hyrax Engine is a fork of O3DE Targeting users of the Designated GNU-Linux distro associated with the Hyrax Engine.

## Why it excists
Hyrax Engine excists to ensure a AAA Game engine always will be accessable to without physically needing to connect to the internet to make 3D Videogames in any step of the creation process..
