# Contributing

For Contributions to Hyrax Engine.

You must understand that Hyrax Engine needs to be Free, this includes all the included components and all included components should focus on being avaliable as either
Offline downloadable or offline bundeled meaning

#Offline Downloadable
Things are stored in Zip/Tar archives and you unpack and install it via stuff such as script automation

#Offline Bundeled 
It is already bundeled and ready to go



All component provides by Hyrax Engine to the users should be tested in various circumstances before going into main line

But the Development line "Braches" Are for testing before merging into main
